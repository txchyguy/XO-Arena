# XO-Arena 🎮

XO-Arena is a Tic Tac Toe Android game developed using Java and Android Studio. It brings the classic X and O game to Android with two-player gameplay, an AI opponent, score tracking, and a clean dark-themed interface.

I built this project to practise Android development and create a simple, enjoyable game.

## Features

- **Two Player Mode:** Play against a friend on the same device.
- **VS AI Mode:** Challenge the computer in single-player mode.
- **Score Tracking:** Keep track of wins and draws.
- **Restart Game:** Start a new match whenever you want.
- **Reset Scores:** Clear the scoreboard and start fresh.
- **Dark Theme:** A clean interface for a comfortable gaming experience.

## Built With

- Java
- Android Studio
- XML for Android UI
- Gradle

## Getting Started

You can run XO-Arena in two ways.

### Option 1: Run the Project in Android Studio

1. Open the [XO-Arena repository](https://github.com/txchyguy/XO-Arena).
2. Click **Code → Download ZIP**.
3. Extract the downloaded ZIP file.
4. Open Android Studio and select **Open**.
5. Choose the extracted `XO-Arena` project folder.
6. Wait for Gradle Sync to finish.
7. Select an Android emulator (Virtual Device) or connect your Android phone using USB debugging.
8. Click the **Run ▶** button to build and launch the app.

### Option 2: Download and Install the APK

1. Open the [XO-Arena repository](https://github.com/txchyguy/XO-Arena).
2. Find the APK file in the repository.
3. Click the APK file, then click **Download raw file**.
4. Transfer the APK to your Android phone if necessary.
5. Open the APK and allow installation from this source if prompted.
6. Tap **Install** and start playing.

**Note:** If the APK does not install, check its compatibility with your Android device.
